# Session Analysis

Analyze captured sessions into patterns and reinforcement signals.

## Pattern Detection

Multi-keyword pattern detection across captured sessions.
Groups related sessions by keyword clusters.

## Reinforcement

- success (+0.1 confidence)
- failure (-0.1 confidence)
- correction (+0.15 confidence)
- reinforce (+0.05 confidence)
- decay (-0.05 confidence)

## Session Lineage

Traces parent-child session relationships.
Identifies broken chains and compression boundaries.
Generates INFERENCE records with evidence tracking.
